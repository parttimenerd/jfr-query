Plot DSL — sugar (the only form, post iter-13)

line { x: ..., y: [...], color: ..., xRefLines: [...] }time series
bar { x: ..., y: [...], layout: stacked|grouped, horizontal }categorical bars
scatter { x, y, size, category }point cloud
histogram { value, bins, logBins, xDomain }distribution
boxplot { value, category }quartile summary
heatmap { x, y, value }2-D density
pie { value, category, innerRadius }composition
flamegraph { frames, value, direction, search }stack traces
table { headers, columnWidths }tabular result
gantt { x0, x1, lane, color }spans/intervals
area { x, y, stack }stacked over time
range { x, lo, hi, bands }min/max + percentiles
| title: ... | width: ... | height: ...panel clauses
| link-x: $var master clamplinked axes (scope is by name — iter-16 §IT16.1)
| name: "id"panel id within a multi-panel cell (§IT15.3)
row { a; b } / col { a; b } / a + b (overlay)composition

Live-variable filter operators (iter-14/15)

WHERE col IN $brushmost-recent brush across notebook (bare form)
WHERE col IN $alias.brushnamespaced — specific cell's brush
WHERE col IN $alias.brush.xaxis-explicit (col ≠ producer axis)
WHERE col IN $alias.panel.brushmulti-panel cell, by panel name (§IT15.3)
WHERE (a, b) IN $heatmap.brushmulti-dim brush (heatmap box-select)
WHERE col IN $hoverhover position (point-equality)
WHERE col IN $hover.categorycategorical hover (pie / flamegraph frame)
WHERE col IN $zoomlinked zoom range / viewport
WHERE col IN $selectionmulti-select / legend / table-row

Variable sigils (iter-16 — two-prefix system)

$xnotebook-local var; coupled across this notebook's cells; persisted via frontmatter vars:
$$xworkspace-global var; shared across notebooks (phase F+); in phase A behaves like $x
Liveness is universal — every reference subscribes. Scope is by name: same name → coupled, different names → independent. No scope= clauses.
