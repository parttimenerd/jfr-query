D — Help content & discoverability

How should we make the notebook easier to learn and explore?

A

PlotHelpModal polish + search

Add full-text search to the PlotHelpModal, make examples copy-paste ready (one-click "Insert example" button), and add a "Cheat sheet" tab with a dense reference table of all clauses. No new surfaces.

Pros

  • Improves what users already open
  • Low complexity

Cons

  • Still requires knowing to open the modal
B

Guided onboarding for new notebooks

When a blank notebook is opened, show a dismissable "Getting started" cell with a short walkthrough: load a JFR file → write a query → add a plot. Uses the existing TemplatedMarkdown cell type. No new infrastructure needed.

Pros

  • Closes the cold-start gap
  • Reuses existing primitives

Cons

  • Only seen once; power users find it annoying
C

Both: modal polish + onboarding ★ recommended

PlotHelpModal gets search + cheat sheet tab + insert-example buttons. New notebooks get a dismissable getting-started cell. Together they cover discovery at both the "I'm new" and "I need to look something up" stages.

Pros

  • Covers both cold-start and day-to-day reference needs

Cons

  • More work, but both pieces are individually contained
