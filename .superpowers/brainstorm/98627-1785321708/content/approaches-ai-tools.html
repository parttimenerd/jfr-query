C — AI tool quality & coverage

Where should we invest in making the AI smarter and more capable?

A

Schema-aware completions & plot-fix

Ghost-text and autocomplete become column-aware: the AI sees the actual column names from the current query result and uses them in suggestions. When a plot fails to render, an inline "Fix with AI" button appears that sends the error + DSL to the model for a corrected version.

Pros

  • Directly reduces "wrong column name" errors
  • Plot-fix closes the most frustrating loop

Cons

  • Completions already get schema — this is a quality tuning effort
B

Richer agent tool repertoire ★ recommended

Add two high-value agent tools: explainCell (AI explains what a cell does and what its results mean, including flamegraph/GC pattern recognition) and suggestPlot (given column names + types, AI proposes the best plot type + config). Both callable from inline-chat.

Pros

  • Closes the "what am I looking at?" gap for JFR newcomers
  • suggestPlot surfaces the right chart for unfamiliar data shapes

Cons

  • Two new tools = two new system-prompt entries + tests
C

System prompt & context quality improvements

Audit and rewrite the AI system prompts: fix the generatePlottingDocsPrompt overflow risk (it can exceed model context on large registries), add JFR domain knowledge (event types, common patterns), tighten the plot DSL spec the model sees so completions are less hallucinated.

Pros

  • Improves all AI features at once
  • No new UI work needed

Cons

  • Quality gains are hard to measure objectively
  • Less visible to users
