Design: Architecture Overview

Four independent work streams, each self-contained. Does this structure look right?

Stream 1 — Contextual editor help

Two additions to CodeMirror 6 extensions in core/frontend/components/editor/plot/:

  • hover.ts extension: When cursor hovers a plot keyword (BRUSH, LINK_X, AXIS_Y, …), look up plotClauseDocs.ts and render the clause signature + description in a CodeMirror tooltip. SQL hover already does this pattern; plot hover mirrors it.
  • lint.ts extension (new diagnostics): Extend the existing plot linter with error-range annotations. Unknown shape names → "Did you mean LINE_CHART?" Unknown clause keyword → suggest nearest match. Renders as red underline + tooltip at the error position.

Files touched: editor/plot/hover.ts (new), editor/plot/lint.ts (extend)

Stream 2 — AI Settings tab polish

Extend SettingsPanel.tsx AI tab:

  • Add a "Mode" section: three labelled cards (Ghost-text / Inline chat / Command palette AI) with one-line descriptions and keyboard shortcut reminders. Active mode highlighted.
  • Add a "Test connection" button: sends a minimal ping prompt to the configured provider and shows ✓ / ✗ with latency or error message.
  • Show active model name next to provider selector.

Files touched: SettingsPanel.tsx, AiService.ts (ping method)

Stream 3 — AI tool quality

  • Column-aware completions: The ghost-text and autocomplete contexts already receive cellResultSchema. Tighten the prompt so the model is explicitly instructed to prefer actual column names over invented ones. Add a column-name validation pass that rejects completions containing unknown identifiers.
  • "Fix with AI" button: When a plot cell shows a render error, display a small "Fix with AI" button below the error message. Clicking it calls inline-chat with a pre-filled prompt: the current DSL + error text → ask model for corrected DSL.
  • explainCell tool: New agent tool. Takes a cell ID, reads its SQL + results + plot config, asks the model to explain what the data shows. JFR-aware: recognises GC pause patterns, flamegraph hotspots, thread contention signatures.
  • suggestPlot tool: New agent tool. Takes column names + types, asks the model to pick the best plot shape + minimal config. Returns a ready-to-paste DSL snippet.

Files touched: AiService.ts, editor/plot/aiPlotContext.ts, editor/aiGhostText.ts, components/plots/PlotRenderer.tsx

Stream 4 — Help content

  • PlotHelpModal search: Add a search input at the top of the modal. Filters shape cards and clause entries by name/keyword in real time. One-click "Insert example" button on each example pastes the snippet into the active cell editor.
  • Cheat sheet tab: New tab in PlotHelpModal: a compact two-column table — clause name on left, one-line description + signature on right. Scannable at a glance.
  • Onboarding cell: When a fresh (empty) notebook is detected on load, prepend a dismissable TemplatedMarkdown cell containing: "Load a JFR file → write a SELECT query → add a PLOT cell." Auto-dismissed when user adds their own cell. Never shown again once dismissed (persisted in localStorage).

Files touched: PlotHelpModal.tsx, NotebookCell.tsx or App.tsx (onboarding injection)

Does this structure look right?

Each stream is independent — they can be implemented in any order without blocking each other. No shared state changes, no new context providers needed.
