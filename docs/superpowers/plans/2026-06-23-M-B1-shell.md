**Goal:** Build the v2 UI shell — `AppShell` (topbar + collapsible sidebar + main + status bar), a static `WelcomeCell`, an `ErrorBoundary` with `?debug=1` crash button, and a theme toggle with `localStorage` persistence. Replace `<div>v2</div>` in `App.tsx`. Implement the six `test.fixme` Playwright tests in `tests/e2e/01-shell-and-ingest.spec.ts` so they pass for real.

**Architecture:** Function components with hooks except `ErrorBoundary` (class — required for `componentDidCatch`). Theme state lives in a `useTheme` hook that reads `localStorage` (key `jfr-theme`), falls back to `prefers-color-scheme`, and sets `document.documentElement.dataset.theme`. Sidebar collapse state is a `useState<boolean>` on `AppShell`; collapse is signalled by a `data-collapsed` attribute on the sidebar element. Keyboard shortcut `⌘\` (Meta+Backslash) is registered with a `useEffect` window keydown listener.

**Tech Stack:** React 19.2, TypeScript 5.8, Vite 6.2, Tailwind v4 (CSS-first via `@theme{}`), Vitest 4.1.9, Playwright 1.61.0, `@testing-library/react` 16.3.0, `@testing-library/user-event` 14.6.1, `@testing-library/jest-dom` 6.6.3.

**Theme selector convention:** `[data-theme="dark"]` and `[data-theme="light"]` on `<html>` (already configured in `src/styles/tokens.css`). NO `.dark` class.

## Pre-resolved decisions

**DECISION: Theme storage.** `localStorage` key `jfr-theme`. Values: `"dark"` | `"light"`. Default: `window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'`. Set `document.documentElement.setAttribute('data-theme', theme)` on mount and on every toggle.

**DECISION: Sidebar collapse.** Toggle `data-collapsed=""` attribute on the `<aside>` element. CSS: `width: 16rem` (256px) when not collapsed, `width: 0; overflow: hidden` when `[data-collapsed]`. The keyboard shortcut `⌘\` (Meta+Backslash) invokes the same toggle as the button. The button has `data-testid="sidebar-toggle"` AND `aria-label="Toggle sidebar"` so both the Playwright spec (which already targets `getByRole('button', { name: /toggle sidebar/i })`) and `data-testid` lookups work.

**DECISION: ErrorBoundary.** Class component (required for React error boundaries — function components cannot implement `componentDidCatch`/`getDerivedStateFromError`). Reads `new URLSearchParams(window.location.search).get('debug') === '1'` once in `render()` to decide whether to show the crash button (`data-testid="crash-button"`, `aria-label="Throw test error"`). `componentDidCatch` logs the error to `console.error`. Fallback JSX uses `role="alert"` and contains a `data-testid="reload-button"` (`aria-label="Reload page"`) that calls `window.location.reload()`. The crash button is rendered by the boundary itself (NOT by `WelcomeCell`) as a small floating button in the bottom-right when `?debug=1`. Clicking it sets boundary state `{ shouldThrow: true }`; on next render the boundary throws synchronously inside a child render component (`<Crasher>`), which lets `getDerivedStateFromError` catch it.

**DECISION: WelcomeCell content.** Static `<section role="region" aria-label="Welcome">` (so the existing `getByRole('region', { name: /welcome/i })` Playwright matcher works) with `data-testid="welcome-cell"`. Contents: app name `JFR SQL Notebook`, tagline `Query Java Flight Recorder data with SQL`, hint `Drop a .jfr.db file to get started`. No interactivity in this milestone.

**DECISION: Topbar.** Fixed height `h-12` (48px). Contains app title (left), theme toggle button (right, `data-testid="theme-toggle"`, `aria-label="Toggle theme"`), and a share-button stub (`data-testid="share-button-stub"`, `aria-label="Share"`, `disabled`).

**DECISION: StatusBar.** Fixed height `h-6` (24px). Single span showing `▣ idle` with `data-testid="status-bar"`. Future milestones replace the text.

**DECISION: Layout primitives.** Use Tailwind utilities (`flex`, `h-screen`, `h-12`, `h-6`, `w-64`, `flex-1`, `overflow-auto`, `border-b`, `border-r`, `bg-[--color-bg-base]`, etc.). No new CSS files outside `tokens.css`. Sidebar collapse width transition uses Tailwind `transition-[width] duration-150`.

**DECISION: RTL setup.** Append `import '@testing-library/jest-dom/vitest'` to the existing `vitest.setup.ts` (do NOT replace — the file already exists and is referenced by `vitest.config.ts` as `./vitest.setup.ts`). No need to edit `vitest.config.ts`. Install three packages: `@testing-library/react@16.3.0 @testing-library/user-event@14.6.1 @testing-library/jest-dom@6.6.3`.

**DECISION: Theme matchMedia in jsdom.** jsdom does not implement `matchMedia`. The `useTheme` hook must guard with `typeof window !== 'undefined' && typeof window.matchMedia === 'function'`. Tests that exercise the theme hook stub `window.matchMedia` per-test via `vi.stubGlobal`.

- [ ] **3.1** Create `frontend-v2/src/components/shell/useTheme.ts`:
  ```typescript
  import { useCallback, useEffect, useState } from 'react';

  export type Theme = 'dark' | 'light';
  const STORAGE_KEY = 'jfr-theme';

  function readInitialTheme(): Theme {
    if (typeof window === 'undefined') return 'dark';
    const stored = window.localStorage?.getItem(STORAGE_KEY);
    if (stored === 'dark' || stored === 'light') return stored;
    if (typeof window.matchMedia === 'function') {
      return window.matchMedia('(prefers-color-scheme: dark)').matches
        ? 'dark'
        : 'light';
    }
    return 'dark';
  }

  function applyTheme(theme: Theme): void {
    if (typeof document === 'undefined') return;
    document.documentElement.setAttribute('data-theme', theme);
  }

  export function useTheme(): { theme: Theme; toggle: () => void } {
    const [theme, setTheme] = useState<Theme>(() => readInitialTheme());

    useEffect(() => {
      applyTheme(theme);
      if (typeof window !== 'undefined') {
        window.localStorage?.setItem(STORAGE_KEY, theme);
      }
    }, [theme]);

    const toggle = useCallback(() => {
      setTheme((t) => (t === 'dark' ? 'light' : 'dark'));
    }, []);

    return { theme, toggle };
  }
  ```

- [ ] **6.1** Create `frontend-v2/src/components/shell/ErrorBoundary.tsx`:
  ```tsx
  import { Component, type ErrorInfo, type ReactNode } from 'react';

  interface Props {
    children: ReactNode;
  }

  interface State {
    error: Error | null;
    shouldThrow: boolean;
  }

  function Crasher(): JSX.Element {
    throw new Error('Manual crash via ?debug=1');
  }

  function isDebug(): boolean {
    if (typeof window === 'undefined') return false;
    return new URLSearchParams(window.location.search).get('debug') === '1';
  }

  export class ErrorBoundary extends Component<Props, State> {
    state: State = { error: null, shouldThrow: false };

    static getDerivedStateFromError(error: Error): Partial<State> {
      return { error };
    }

    componentDidCatch(error: Error, info: ErrorInfo): void {
      // eslint-disable-next-line no-console
      console.error('[ErrorBoundary]', error, info.componentStack);
    }

    private handleReload = (): void => {
      window.location.reload();
    };

    private handleCrash = (): void => {
      this.setState({ shouldThrow: true });
    };

    render(): ReactNode {
      if (this.state.error) {
        return (
          <div
            role="alert"
            className="m-8 max-w-xl rounded border border-[--color-accent-amber] bg-[--color-bg-surface] p-6"
          >
            <h2 className="text-lg font-semibold text-[--color-fg-base]">
              Something went wrong.
            </h2>
            <pre className="mt-2 overflow-auto rounded bg-[--color-bg-overlay] p-2 text-xs text-[--color-fg-muted]">
              {this.state.error.message}
            </pre>
            <button
              type="button"
              data-testid="reload-button"
              aria-label="Reload page"
              onClick={this.handleReload}
              className="mt-4 rounded border border-[--color-border] px-3 py-1 text-sm text-[--color-fg-base] hover:bg-[--color-bg-overlay]"
            >
              Reload
            </button>
          </div>
        );
      }

      return (
        <>
          {this.state.shouldThrow ? <Crasher /> : null}
          {this.props.children}
          {isDebug() ? (
            <button
              type="button"
              data-testid="crash-button"
              aria-label="Throw test error"
              onClick={this.handleCrash}
              className="fixed bottom-4 right-4 rounded border border-[--color-accent-amber] bg-[--color-bg-surface] px-3 py-1 text-xs text-[--color-accent-amber]"
            >
              Throw test error
  ```

- [ ] **7.1** Create `frontend-v2/src/components/shell/AppShell.tsx`:
  ```tsx
  import { useCallback, useEffect, useState, type ReactNode } from 'react';
  import { Topbar } from './Topbar';
  import { Sidebar } from './Sidebar';
  import { StatusBar } from './StatusBar';
  import { ErrorBoundary } from './ErrorBoundary';

  interface AppShellProps {
    children: ReactNode;
  }

  export function AppShell({ children }: AppShellProps): JSX.Element {
    const [collapsed, setCollapsed] = useState(false);

    const toggle = useCallback(() => {
      setCollapsed((c) => !c);
    }, []);

    useEffect(() => {
      function onKey(e: KeyboardEvent): void {
        if (e.metaKey && e.key === '\\') {
          e.preventDefault();
          toggle();
        }
      }
      window.addEventListener('keydown', onKey);
      return () => window.removeEventListener('keydown', onKey);
    }, [toggle]);

    return (
      <ErrorBoundary>
        <div className="flex h-screen flex-col bg-[--color-bg-base] text-[--color-fg-base]">
          <Topbar />
          <div className="flex flex-1 min-h-0">
            <div className="flex items-start">
              <Sidebar collapsed={collapsed} />
              <button
                type="button"
                data-testid="sidebar-toggle"
                aria-label="Toggle sidebar"
                onClick={toggle}
                className="m-2 rounded px-2 py-1 text-xs text-[--color-fg-muted] hover:bg-[--color-bg-overlay]"
              >
                {collapsed ? '›' : '‹'}
              </button>
            </div>
            <main className="flex-1 overflow-auto">{children}</main>
          </div>
          <StatusBar />
        </div>
      </ErrorBoundary>
    );
  }
  ```
